# Expérience exp-00101

## Décision

Hypothèse « sémantique seule suffisante » rejetée. La voie identité est conservée pour l'étape B
des scales V5. Aucun checkpoint n'est promu et aucun benchmark en partie n'a été exécuté.

## Type

Expérience de qualité, limitée à une attribution offline multi-seed. Le résultat de partie et la
gate de promotion restent non renseignés.

## Hypothèse

La voie sémantique structurée de V5 pourrait maintenir la qualité de la politique sans utiliser
`card_definition_id`. Le contrôle V5 normalisé devait être comparé à une candidate entraînée avec
la voie identité supprimée à l'entrée de `card_fusion`.

## Recette

- Architecture : `structured_semantic_v5_fusion_experiment`.
- Contrôle : `exp00101-v005-fusion-control`, scales `1,0 / 1,0`, normalisation L2.
- Ablation : `exp00102-v005-fusion-without-identity`, même configuration avec identité supprimée.
- Dataset : `artifacts/imitation_dataset/v008_vs_random_v007_normalized_100k.jsonl`.
- Entraînement : imitation, 1 epoch, 10 000 records, learning rate `0,001`, un thread PyTorch.
- Seeds d'entraînement : `50100`, `50102`, `50103`.
- Split : `game_id`, `split_seed=50101`.
- Holdout offline : `non_train`, 19 329 records par run.
- Les deux candidates ont utilisé le même dataset, split, recette et seed pour chaque paire.

## Résultats offline par seed

| Seed | Contrôle top-1 | Ablation top-1 | Delta | Contrôle top-3 | Ablation top-3 |
|---:|---:|---:|---:|---:|---:|
| 50100 | 80,28 % | 76,15 % | -4,13 points | 97,13 % | 96,51 % |
| 50102 | 80,31 % | 76,69 % | -3,62 points | 97,23 % | 96,35 % |
| 50103 | 80,72 % | 77,26 % | -3,46 points | 97,47 % | 96,60 % |

Sur les deux seeds de confirmation `50102` et `50103`, la moyenne est :

- top-1 : contrôle `80,52 %`, ablation `76,98 %`, delta `-3,54` points ;
- top-3 : contrôle `97,35 %`, ablation `96,47 %`, delta `-0,88` point ;
- regret heuristique : contrôle `1,5737`, ablation `1,6163`, soit `+0,0426` pour l'ablation.

En incluant le run initial `50100`, les trois seeds donnent un delta top-1 moyen de `-3,74`
points et un delta top-3 moyen de `-0,79` point.

## Validation d'entraînement

Sur les deux seeds de confirmation, l'ablation dégrade en moyenne :

- le top-1 de validation de `3,40` points ;
- la précision pairwise de `2,89` points ;
- la loss de `+0,0403` ;
- le rang moyen choisi de `+0,0618`.

Les régressions offline sont principalement observées sur `activate_champion`, `play_card` et
`recruit_mercenary`, ainsi que sur la phase `play`. Les décisions d'achat sont beaucoup moins
affectées et ne compensent pas la baisse globale.

## Limites

- Une seule epoch et 10 000 records ont été utilisés par run.
- La confirmation porte sur deux seeds supplémentaires, trois avec le run initial.
- Aucun résultat de partie, aucune latence comparative et aucune gate longue ne sont disponibles.
- Le top-1 et le regret restent des métriques offline vis-à-vis du teacher ; ils ne mesurent pas
  directement la force contre Random, v007, v008 ou les profils neural.

## Décision opérationnelle

La répétition sur les seeds `50102` et `50103` confirme suffisamment, pour ce protocole, que la
voie identité apporte une information utile. Le mode `without_identity` est retiré du code et de
la liste des candidates. Le scorer V5 normalisé, ses deux scales et le profil contrôle sont
conservés pour l'étape B.

L'étape B testera séparément `id_scale=0,5, semantic_scale=1,5` et
`id_scale=1,5, semantic_scale=0,5`, avec le contrôle V5 `1,0 / 1,0`.
